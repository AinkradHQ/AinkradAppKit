# HostServices.signals (generation 9). A new protocol requirement, which the
# digester rightly flags — this is the break library evolution does NOT cover.
#
# It cannot stop an installed plugin from LOADING: nothing outside the host
# conforms to HostServices in production. Verified rather than assumed, because
# the freeze test used to claim the host was the ONLY conformer and that was
# wrong — Raven, Rune and GitMage each fake one in their test support, and all
# three are updated in this generation. Plugins CONSUME HostServices; they do
# not implement it, so a compiled bundle keeps loading while those repos' test
# suites need a one-line addition.
#
# Deliberately here and not in breakage-allowlist.txt, which is for accepted ABI
# breaks. And deliberately not silenced by regenerating the baseline: that would
# hide the NEXT added requirement too, which is the one that might genuinely
# break something.
Var HostServices.signals has been added as a protocol requirement

# HostServices.mode (generation 11). The same class of change as `signals`
# above, reviewed the same way.
#
# It cannot stop an installed plugin from LOADING: a plugin CALLS `host.mode`,
# it never implements it, and in production only the host conforms to
# HostServices. A generation-10 bundle never calls it, so it needs no witness.
#
# It DOES break the compilation of the fake conformances in Raven's, Rune's and
# Git Mage's test support — exactly as `signals` did at generation 9. That is a
# source break in three repos, fixed when each moves its pin, not a load
# failure in the field.
#
# `AinkradAppModes` is deliberately NOT here: it is a separate protocol found by
# cast, so it adds no requirement to anything and needs no exemption.
Var HostServices\.mode has been added as a protocol requirement

# HostServices.overlaySize (generation 11). Same class and same reasoning as
# `mode` above and `signals` at generation 9: a plugin CALLS it and never
# implements it, so no installed bundle needs a witness for it.
#
# Added within generation 11 rather than bumping to 12: 11 has not been
# released, so no bundle in the field was built against the narrower protocol.
# If 11 ships before this lands, this exemption is wrong and the generation must
# move instead.
Var HostServices\.overlaySize has been added as a protocol requirement
